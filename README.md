# Make the AI Judge Feel Proud: A Family Scene

Entry for the [make.fun bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2).

## The entry

> Every Sunday, Dad sets a place for Grandma, then eats her dessert "so it doesn't go to waste."
> Mum rolls her eyes. None of us correct him — some love languages come with a fork.

A two-line family scene: a small Sunday ritual, a father's quiet way of
keeping Grandma at the table, and a family that knows better than to correct
him. Some love languages come with a fork.

## How it works

`main.py` (Python standard library only) writes the scene to
`/output/entry.txt` using plain `open()` with an explicit `chmod 644`, and
self-checks that the text is within the kit's 1–280 character limit before
writing.

Run it with:

```sh
python3 main.py
```
